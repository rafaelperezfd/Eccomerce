Uma plataforma completa de e-commerce desenvolvida em **Python** utilizando o framework **Django**. O sistema inclui catálogo de produtos, navegação por categorias, carrinho de compras dinâmico, gestão de utilizadores e um painel de administração completo para controlo de stock e pedidos.

---

## 🚀 Funcionalidades

### 🛒 **Área do Cliente**
- **Catálogo de Produtos:** Exibição dinâmica de produtos com filtros por categoria, preço e barra de pesquisa.
- **Detalhes do Produto:** Página dedicada com fotos, descrição técnica, avaliação e disponibilidade em stock.
- **Carrinho de Compras:** Adição/remoção de itens com cálculo automático de subtotal, portes de envio e valor total.
- **Autenticação:** Registo, login, recuperação de palavra-passe e perfil do utilizador com histórico de pedidos.
- **Simulação de Checkout:** Fluxo de finalização de compra com seleção de endereço de entrega e método de pagamento.

### ⚙️ **Painel Administrativo**
- **Gestão de Inventário:** Registo, edição e remoção de produtos, categorias e imagens.
- **Gestão de Pedidos:** Acompanhamento do estado das encomendas (`Pendente`, `Pago`, `Enviado`, `Entregue`).
- **Controlo de Utilizadores:** Gestão de clientes e permissões de acesso.

---

## 🛠️ Tecnologias Utilizadas

- **Linguagem Principal:** Python 3.11+
- **Framework Web:** Django / Django REST Framework
- **Banco de Dados:** SQLite (Desenvolvimento) / PostgreSQL (Produção)
- **Front-end:** HTML5, CSS3 / Tailwind CSS, JavaScript (ES6+)
- **Ferramentas & Bibliotecas:** Pillow (processamento de imagens), Git, GitHub, VS Code
